Internship · 8 Weeks

Where code meets the cutting table.

I joined because it combined two things I care about — technology and fashion design — and left having built a pattern generator that produces files professional design software can open.

01 — The project

Parametric pattern generator

A Python tool that takes measurements from 3D body scans and generates garment patterns automatically, exported as DXF and displayed in LibreCAD with all measurements labelled.

02 — The challenge

When the API said no

The Style3D API couldn't display text in the 2D window as planned. I researched alternatives and pivoted to LibreCAD — a lesson in adapting when the first approach fails.

03 — What I learned

Technical + practical

I learned Python geometry (curves, distances and angles), how to read and write files, and the DXF file format. I also used Lectra to digitise patterns
